# 活动面板日期兼容

## 现象与根因

角色信息面板只转圈后消失。用户在2026-11-07北京时间00:26左右连续三次复现；目标活动资源成功加载，前两次完整错误链一致，第三次日志被上限截断。

目标类为`mmo.activity231229.petfightspace3.panel.personalinfo.PFSpace3_PersonalInfoPl`。游戏日期`2024/1/5 02:00:00`被引擎拒绝，赛季起始时间变成无效值，得到空赛季列表，初始化时触发#1009。

只修改四位年开头日期解析中月/日的长度判断，使1～2位月/日均可解析；不修改活动SWF和服务器协议。入口：`src/optimization/engine/core/src/avm2/globals/date.rs`，登录器独立源码也包含此前日期修正。

修复前新增日期分词和真实Date构造测试失败，旧Flash样例仍通过；修复后四种补零组合、官方日期样例、非法边界、赛季编号及date_parse录制输出检查通过，加宿主与窗口检查共11项通过。

**尚未收到角色面板专项在线验收。** 背包B组“显示正常”不能替代该面板验收。
