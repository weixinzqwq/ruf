# 窗口拖动

## 修改与结果

Windows拖动或缩放窗口时会进入嵌套消息循环，普通更新入口暂停，导致游戏画面不持续刷新。

进入拖动/缩放时启用10ms唤醒定时器，通过winit用户事件调用同一更新绘制路径；仍按同一时钟计算经过时间。只保留一个待处理唤醒，退出、销毁或守卫释放时清理定时器和钩子。

入口：`src/optimization/engine/desktop/src/window_move.rs`、`app.rs`、`custom_event.rs`。现有登录器线也保留该修正。

隐藏窗口嵌套循环回归覆盖暂停期间更新、退出停止、二次拖动恢复、释放后停止；构建与宿主检查通过。用户已明确确认窗口修正后没有问题，因此状态为**在线已验收**。它不代表背包或战斗性能问题已经解决。

## 复查步骤

1. 用保留测试包手动登录并进入有动画的地图。
2. 持续拖动和调整窗口尺寸，观察动画是否继续，结束后是否正常响应。
3. 再次拖动、最小化恢复并退出，观察是否出现停止更新、加速或残留窗口。
4. 若修改消息循环，再运行桌面`window_move`回归，不改游戏逻辑帧率来掩盖问题。

证据：[窗口交付记录](evidence/history/window-move-20261106/delivery.json)。旧专用构建已被后续版本替代并清理；不要把历史交付时的pending状态覆盖成当时已验收。
