# 登录器功能与测试

## 独立源码与当前版本

2026-11-26 起，本页描述的旧登录器保存在本地 Git 标签 `archive/launcher-pre-t0-20261126`。该版本的源码位于 `src/launcher/engine`、`src/launcher/native-core`，启动桥位于 `src/launcher/source/launcher-bridge`。[归档恢复步骤](工程构建与迁移.md#当前目录)

保留[正式登录器入口](../dist/aola-launcher-20261107-release/run-launcher.cmd)。新目录首次使用需手动登录；数据保存在包内`aola-launcher-data`，旧登录资料按用户选择留在原位置。

## 已实现内容

工具栏包括目标帧率、画质、静音、日志及收发记录界面；发送文本解析和非阻塞队列；会话变化时停止队列；记录容量限制及敏感登录字段隐藏。

Rust观察现有Ruffle通道，独立启动桥调用游戏自身`ActClientSender`，连接和加密仍由游戏持有。桥只替换匹配的启动资源。当前范围不含战斗回放、阵容、主题与形态功能。

`#send`与`#time`格式检查、暂停/清空/停止和导入导出等细节保留在[历史说明归档](archive/历史说明与脚本.zip)的`LAUNCHER.md`。已提交给游戏不等于网络送达或服务器成功；本轮整理不执行发包或游戏操作。

## 测试进度

2026-11-07最终37项相关测试、Release构建及`--help`检查通过；离线预览观察到中文工具栏和收发记录窗口。双击EXE进入登录器、保存播放设置恢复和显式帧率优先级已处理。

**真实登录、实际收发包和服务器结果仍待用户专项验收。** 离线模拟和源码调用链不是线上成功证明。

## 操作与验证

1. 运行保留入口，手动完成官方登录，检查窗口、工具栏和播放设置。
2. 默认日志关闭；需要定位时由用户启用，再按对应时间查看本地诊断。
3. 发送能力仅在用户自行确认具体命令与目标后测试；观察“已提交”、网络记录和服务器响应各自的含义。
4. 构建或测试执行`src/tools/build.ps1 -Component launcher -Action build/test`；不会覆盖保留发布包。完整命令见[工程构建与迁移](工程构建与迁移.md)。
